{%- comment -%} The one post card. Every list of posts on the site renders this, so a card looks the same everywhere. Only the size changes. post: required. style: optional. "wide" spans the whole column with a big title (the newest post on page 1, and Read next). "small" drops the description and shrinks the title (Keep reading, 404). lead: optional. The newest post on page 1. Its photo runs edge to edge on phones. priority: optional. true when the photo is likely above the fold. {%- endcomment -%} {%- assign card = include.post -%} {%- assign card_size = include.style | default: "regular" -%} {%- if card_size == "wide" -%} {%- assign card_sizes = "(min-width: 62.5rem) 60rem, 100vw" -%} {%- else -%} {%- assign card_sizes = "(min-width: 62.5rem) 29rem, (min-width: 40rem) calc((100vw - 4.5rem) / 2), 100vw" -%} {%- endif -%}
